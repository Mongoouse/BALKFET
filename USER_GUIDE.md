# Felhasználói útmutató

## Alkalmazás használata
Az alkalmazás egy egyszerű időjárás-előrejelző rendszer.

### Frontend
- Nyisd meg a böngészőben: http://localhost:4200
- Kattints a "Betöltés" gombra az időjárás adatok megjelenítéséhez.

### Backend API
- Swagger UI: http://localhost:5000/swagger
- Végpont: GET /WeatherForecast

## Funkciók
- Időjárás adatok lekérése és megjelenítése.
